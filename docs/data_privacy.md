# Data Privacy Rules

This public demonstration uses fully synthetic creator, collaboration, campaign, and risk data.

It contains no real client data, internal identifiers, real creator handles, private contact information, internal notes, or claims about real people. Synthetic brands and evidence-source labels are used throughout.

Before publishing any future dataset:

1. Confirm every person and brand record is synthetic.
2. Search for real handles, URLs, emails, phone numbers, and internal IDs.
3. Do not copy profile summaries or risk descriptions from internal sources.
4. Treat a blank value as unknown, never as proof that a condition is false.
5. Keep any private development data outside the public repository.
